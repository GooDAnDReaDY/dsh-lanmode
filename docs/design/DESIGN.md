# DESIGN.md — @goodandready/dsh-lanmode

## Product / Purpose
- **Назначение**: Сетевой и мобильный шлюз для DeepSeek Harness Web UI: устранение ограничений незащищенного HTTP, авто-выпуск локального Root CA и TLS-сертификатов, mDNS-анонс `dsh.local`, адаптивный тач-слой для смартфонов, безопасный туннель Cloudflare и контроль сессий подключенных устройств.
- **Аудитория**: Разработчики и пользователи DeepSeek Harness, желающие полноценно управлять своими агентами со смартфона, планшета или удаленного ПК без необходимости сложной ручной настройки обратных прокси и сертификатов.
- **Статус**: Активная разработка (v0.7.0).

## User Surfaces
- **Web/UI**:
  - Мобильный адаптивный тач-слой (Portrait mode, экран < 1024px): 44px touch targets, 16px anti-zoom, safe areas, жесты свайпа сайдбара, автоскрытие второстепенных панелей.
  - Быстрый доступ в подвале сайдбара (`sidebar.footer` / `sidebar.rail`): компактная иконка смартфона с вызовом поповера Quick QR.
  - Поповер быстрого входа: чистый SVG QR-код, переключатель LAN / WAN, кнопка копирования URL, ссылка на скачивание Root CA.
  - Индикатор подключенного мобильного устройства («📱 Смартфон на связи») на десктопе.
- **DSH UI / settings / slots**:
  - Карточка в Настройки → Плагины (`settings.plugin.item`, key: `dsh-lanmode`).
  - Управление туннелями Cloudflare (Quick / Named).
  - Реестр сопряженных устройств (Device Roster): название устройства (User-Agent), статус онлайн (`lastSeenAt`), кнопка индивидуального отзыва и аварийный Kill Switch.
  - Настройка «Enter = Новая строка» (`mobileEnterSends`).
  - Настройка «Принудительно десктопный вид» (`forceDesktopMode`).
- **API**:
  - `/dsh-lanmode/health`: JSON/HTML статус сервера и точек крепления.
  - `/dsh-lanmode/ca.crt`: скачивание 10-летнего Root CA сертификата.
  - `/dsh-lanmode/qr`: векторный SVG QR-код для любого URL.
  - `/dsh-lanmode/manifest.json`: расширенный PWA манифест.
  - `/dsh-lanmode/probe`: диагностический пинг сетевого порта (Self-Test).
  - `/dsh-lanmode/devices`: API управления доверенными устройствами.
- **CLI / Терминал**:
  - Инструмент `/mobileqr` в чате с агентом.
  - Вывод ASCII QR-кода в stdout при запуске сервера `dsh web`.
- **Документация**:
  - `README.md`, `README.ru.md`, `README.zh.md`, `docs/design/DESIGN.md`, `docs/plans/`.

## Visual Direction
- **Атмосфера**: Нативная интеграция в DSH, чистота, утилитарность, отсутствие инородных визуальных слоев.
- **Утверждённые референсы**: Официальные компоненты DSH UI, карточки `settings.plugin.item`, подвал `sidebar.footer`.
- **Не копировать**: Тяжелые сторонние фреймворки, внешние веб-шрифты, несоответствующие CSS-переменные. Использовать строго канонические токены DSH `--dsw-*`.

## Foundations
- **Цвета и роли**:
  - Фоновые слои: `var(--dsw-alias-bg-layer-1)`, `var(--dsw-alias-bg-layer-2)`, `var(--dsw-alias-bg-layer-3)`.
  - Границы: `var(--dsw-alias-border-l2)`.
  - Текст: `var(--dsw-alias-label-primary)`, `var(--dsw-alias-label-secondary)`, `var(--dsw-alias-label-tertiary)`.
  - Акценты: Зеленый статус подключения (`#22c55e`), желтый предупреждающий (`#eab308`).
- **Типографика**: Системный стек `system-ui, -apple-system, sans-serif`. В полях ввода на экранах `< 1024px` строго `16px` для предотвращения автозума в iOS.
- **Сетка, отступы, responsive**:
  - Кликабельные зоны для touch: минимум `44×44px`.
  - Отступы снизу: `env(safe-area-inset-bottom, 12px)`.
  - Закругления: `12px` (карточки), `8px` (кнопки и бейджи).
- **Accessibility**: Семантические теги (`button`, `li`, `input`), атрибуты `aria-expanded`, `aria-label`.

## Components And States
- **Компоненты**:
  - `LanModeCard`: аккордеонная карточка в настройках.
  - `QuickQrPopover`: плавающий поповер быстрого доступа в сайдбаре.
  - `DeviceRoster`: список активных устройств с бейджами онлайн/офлайн.
  - `FloatingSidebarTrigger`: плавающий FAB на мобильных при свернутом меню.
- **Loading / empty / error / success**:
  - Статусы сетевого прокси и туннеля отображаются в реальном времени.
  - Ошибки фаервола и занятых портов содержат понятные подсказки на русском и английском.

## User Flows
- **Критические сценарии**:
  1. *Вход с телефона по QR*: Пользователь сканирует QR на экране ПК → открывается защищенный интерфейс без 401 ошибки → активируется мобильный слой → устройство фиксируется в Device Roster.
  2. *Вход вне дома (WAN)*: Пользователь включает Cloudflare Tunnel → генерируется публичный URL → доступ по 8-значному PIN-коду.
  3. *Отзыв доступа*: Пользователь нажимает «Отозвать» у неизвестного устройства или жмет «Kill Switch» → сессии немедленно сбрасываются.

## Do / Don't
- **Do**:
  - Сохранять нулевую внешнюю зависимость базового режима (Zero-dependency pure JS).
  - Использовать css safe-area переменные.
  - Поддерживать двунаправленную синхронизацию состояния сессий.
- **Don't**:
  - Не блокировать десктопный режим при наличии мобильного слоя.
  - Не зашивать статические порты или IP-адреса в интерфейсе.

## Locked Design Decisions
- 2026-09-03 — Фича «Enter на смартфоне»: настраиваемый переключатель `mobileEnterSends` (по умолчанию: `false` — Enter вставляет перенос строки, отправка по кнопке со стрелкой).
- 2026-09-03 — Мобильный адаптивный слой подключается прозрачно через CSS/JS инъекцию в `index.html` и не требует пересборки клиентских бандлов ядра DSH.
- 2026-09-03 — Поддержка Cloudflare туннелей выполняется как опциональный аддон через динамическую загрузку бинарника `cloudflared` без раздувания npm-пакета.
- 2026-09-05 — Отложенная регистрация слотов UI: в архитектуре DSH ui-slots дочерние слоты (`settings.plugin.item`, `sidebar.footer.action`) объявляются динамически родительскими компонентами; их регистрация выполняется строго через `ctx.slots.inject` с fallback на прямой `register`.
