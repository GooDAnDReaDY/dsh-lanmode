# DESIGN.md — @goodandready/dsh-lanmode

## Product / Purpose
- **Назначение**: Сетевой и мобильный шлюз для DeepSeek Harness Web UI: устранение ограничений незащищенного HTTP, авто-выпуск локального Root CA и TLS-сертификатов, mDNS-анонс `dsh.local`, адаптивный тач-слой для смартфонов, безопасный туннель Cloudflare и контроль сессий подключенных устройств.
- **Аудитория**: Разработчики и пользователи DeepSeek Harness, желающие полноценно управлять своими агентами со смартфона, планшета или удаленного ПК без необходимости сложной ручной настройки обратных прокси и сертификатов.
- **Статус**: Активная разработка (v0.7.0).

## User Surfaces
- **Web/UI**:
  - Мобильный адаптивный тач-слой (Portrait mode, экран < 1024px): 44px touch targets, 16px anti-zoom, safe areas, жесты свайпа сайдбара, автоскрытие второстепенных панелей.
  - Быстрый доступ в подвале сайдбара (`sidebar.footer` / `sidebar.rail`): компактная иконка смартфона с вызовом поповера Quick QR.
  - Поповер быстрого входа: чистый SVG QR-код, переключатель LAN / WAN, кнопка копирования URL, ссылка на скачивание Root CA.
  - Индикатор подключенного мобильного устройства («📱 Смартфон на связи») на десктопе.
- **DSH UI / settings / slots**:
  - Карточка в Настройки → Плагины (`settings.plugin.item`, key: `dsh-lanmode`).
  - Управление туннелями Cloudflare (Quick / Named).
  - Реестр сопряженных устройств (Device Roster): название устройства (User-Agent), статус онлайн (`lastSeenAt`), кнопка индивидуального отзыва и аварийный Kill Switch.
  - Настройка «Enter = Новая строка» (`mobileEnterSends`).
  - Настройка «Принудительно десктопный вид» (`forceDesktopMode`).
- **API**:
  - `/dsh-lanmode/health`: JSON/HTML статус сервера и точек крепления.
  - `/dsh-lanmode/ca.crt`: скачивание 10-летнего Root CA сертификата.
  - `/dsh-lanmode/qr`: векторный SVG QR-код для любого URL.
  - `/dsh-lanmode/manifest.json`: расширенный PWA манифест.
  - `/dsh-lanmode/probe`: диагностический пинг сетевого порта (Self-Test).
  - `/dsh-lanmode/devices`: API управления доверенными устройствами.
- **CLI / Терминал**:
  - Инструмент `/mobileqr` в чате с агентом.
  - Вывод ASCII QR-кода в stdout при запуске сервера `dsh web`.
- **Документация**:
  - `README.md`, `README.ru.md`, `README.zh.md`, `docs/design/DESIGN.md`, `docs/plans/`.

## Visual Direction
- **Атмосфера**: Нативная интеграция в DSH, чистота, утилитарность, отсутствие инородных визуальных слоев.
- **Утверждённые референсы**: Официальные компоненты DSH UI, карточки `settings.plugin.item`, подвал `sidebar.footer`.
- **Не копировать**: Тяжелые сторонние фреймворки, внешние веб-шрифты, несоответствующие CSS-переменные. Использовать строго канонические токены DSH `--dsw-*`.

## Foundations
- **Цвета и роли**:
  - Фоновые слои: `var(--dsw-alias-bg-layer-1)`, `var(--dsw-alias-bg-layer-2)`, `var(--dsw-alias-bg-layer-3)`.
  - Границы: `var(--dsw-alias-border-l2)`.
  - Текст: `var(--dsw-alias-label-primary)`, `var(--dsw-alias-label-secondary)`, `var(--dsw-alias-label-tertiary)`.
  - Акценты: Зеленый статус подключения (`#22c55e`), желтый предупреждающий (`#eab308`).
- **Типографика**: Системный стек `system-ui, -apple-system, sans-serif`. В полях ввода на экранах `< 1024px` строго `16px` для предотвращения автозума в iOS.
- **Сетка, отступы, responsive**:
  - Кликабельные зоны для touch: минимум `44×44px`.
  - Отступы снизу: `env(safe-area-inset-bottom, 12px)`.
  - Закругления: `12px` (карточки), `8px` (кнопки и бейджи).
- **Accessibility**: Семантические теги (`button`, `li`, `input`), атрибуты `aria-expanded`, `aria-label`.

## Components And States
- **Компоненты**:
  - `LanModeCard`: аккордеонная карточка в настройках.
  - `QuickQrPopover`: плавающий поповер быстрого доступа в сайдбаре.
  - `DeviceRoster`: список активных устройств с бейджами онлайн/офлайн.
  - `FloatingSidebarTrigger`: плавающий FAB на мобильных при свернутом меню.
- **Loading / empty / error / success**:
  - Статусы сетевого прокси и туннеля отображаются в реальном времени.
  - Ошибки фаервола и занятых портов содержат понятные подсказки на русском и английском.

## User Flows
- **Критические сценарии**:
  1. *Вход с телефона по QR*: Пользователь сканирует QR на экране ПК → открывается защищенный интерфейс без 401 ошибки → активируется мобильный слой → устройство фиксируется в Device Roster.
  2. *Вход вне дома (WAN)*: Пользователь включает Cloudflare Tunnel → генерируется публичный URL → доступ по 8-значному PIN-коду.
  3. *Отзыв доступа*: Пользователь нажимает «Отозвать» у неизвестного устройства или жмет «Kill Switch» → сессии немедленно сбрасываются.

## Do / Don't
- **Do**:
  - Сохранять нулевую внешнюю зависимость базового режима (Zero-dependency pure JS).
  - Использовать css safe-area переменные.
  - Поддерживать двунаправленную синхронизацию состояния сессий.
- **Don't**:
  - Не блокировать десктопный режим при наличии мобильного слоя.
  - Не зашивать статические порты или IP-адреса в интерфейсе.

## Locked Design Decisions
- 2026-09-03 — Фича «Enter на смартфоне»: настраиваемый переключатель `mobileEnterSends` (по умолчанию: `false` — Enter вставляет перенос строки, отправка по кнопке со стрелкой).
- 2026-09-03 — Мобильный адаптивный слой подключается прозрачно через CSS/JS инъекцию в `index.html` и не требует пересборки клиентских бандлов ядра DSH.
- 2026-09-03 — Поддержка Cloudflare туннелей выполняется как опциональный аддон через динамическую загрузку бинарника `cloudflared` без раздувания npm-пакета.
- 2026-09-05 — Отложенная регистрация слотов UI: в архитектуре DSH ui-slots дочерние слоты (`settings.plugin.item`, `sidebar.footer.action`) объявляются динамически родительскими компонентами; их регистрация выполняется строго через `ctx.slots.inject` с fallback на прямой `register`.
- 2026-09-05 — Реактивная привязка карточки настроек к settingsScope (#95): слот settings.plugin.item запрашивает сервис settingsScope, слушает живые обновления через subscribe / getSnapshot и сохраняет поля формы (mode, directPort, tls, allow, unlockPrivileged, lanPinRef) с валидацией портов и сбором ошибок по всем полям.
- 2026-09-05 — Хранение секретов через Credential References (#96): поля lanPinRef и tunnelTokenRef поддерживают безопасные ссылки на сервис учётных данных DSH (ctx.credentials) и переменные окружения вместо хранения открытых секретов в снимках настроек; прямые поля lanPin и tunnelToken сохранены в режиме Deprecated для обратной совместимости.
- 2026-09-05 — Управление жизненным циклом клиентских слушателей (#97): клиентские обработчики turn/end, approval/asked, visibilitychange и focus регистрируются строго внутри ctx.effect и возвращают функции очистки (disposables), исключая утечки памяти при горячей перезагрузке плагина в веб-интерфейсе.
- 2026-09-07 — Оптимизация стабильности, стриминга и неинвазивность интерфейса (#100):
  1. `DeviceRegistry` переведён на неблокирующую отложенную запись (`scheduleSave`, 5с дебаунс, `unref()`) с немедленным `flush()` при отзыве сессий и остановке плагина.
  2. Стриминг LLM-ответов (`text/event-stream`, `x-accel-buffering: no`) исключён из буферизации gzip/brotli компрессоров, обеспечивая нулевую задержку вывода токенов.
  3. WebSocket переведён на стандартный сетевой TCP Keep-Alive (`setKeepAlive(true, 25000)`), исключая инъекцию сырых байтов и падение соединений по Error 1002.
  4. Устранён паразитный оверинжиниринг: удалены monkey-patching `HTMLElement.prototype.focus`, блокировка `Enter` через `stopPropagation` и принудительное скрытие сторонних плагинов через CSS `!important`.
  5. Фоновые таймеры опроса реестра устройств и туннеля активны только при развёрнутой карточке настроек плагина.
- 2026-09-09 — Аутентификация по логину и паролю и фирменная страница входа (#103):
  1. *Двухуровневая защита любого входа*: опция `passwordAuth` блокирует неавторизованный доступ ко всем HTTP-запросам (HTML, JSON, REST API) и WebSocket-соединениям на уровне прямого моста `bridge.js` и раннего клиентского перехватчика `shim.js`. Публичными остаются только маршруты аутентификации `/dsh-lanmode/auth/*`, favicon и Root CA.
  2. *Фирменная страница входа*: рендерится сервером без внешних зависимостей в нативной палитре Catppuccin Mocha (`#11111b`, `#181825`, `#313244`, `#cdd6f4`, индиго `#6366f1`), с плавным анимированным появлением, интерактивной валидацией, переключателем видимости пароля, защитой от iOS auto-zoom (`16px` шрифты, `44px` кнопки) и индикацией защищённого HTTPS соединения.
  3. *Безопасность сессий и криптография*:
     - Проверка паролей выполняется через `crypto.timingSafeEqual` с предварительной проверкой длины буферов, полностью исключая тайминг-атаки.
     - Сессионные токены генерируются через `crypto.randomBytes(32)` и сохраняются в безопасных куках `dsh_auth_session` (`HttpOnly; SameSite=Lax; Path=/`).
     - Защита от подбора паролей (Brute-force protection): автоматическая блокировка по IP-адресу на 30 секунд при превышении 5 неверных попыток ввода.
     - Поддержка ссылок на секреты (`authPasswordRef`) через защищённое хранилище `credentials` DSH / переменные окружения, исключающая сохранение открытого пароля в JSON-снимках настроек.
  4. *Интеграция в карточку настроек*: управление опцией `passwordAuth`, полями `authUser`, `authPassword`, `authPasswordRef` через `settingsScope` и кнопка быстрого выхода «Выйти из системы» (`POST /dsh-lanmode/auth/logout`).


- 2026-09-09 — Устранение гонки запасного пути конфигурации со службой настроек (#106):
  1. *Декларация зависимостей*: Сервис `settings` включён в `export const inject = ['webServer', 'settings']`, что гарантирует нативное ожидание готовности службы ядром Cordis перед вызовом `apply()`.
  2. *Устранение таймера-гонки*: Гоночный таймер `setTimeout(..., 2000)` удалён из `apply()`. Настройки считываются непосредственно при старте плагина.
  3. *Прозрачность источника конфигурации и обработка ошибок*: Поля `configSource` (`settings` | `row` | `defaults`) и `configWarning` сохраняются в состоянии и отображаются на странице диагностики `/dsh-lanmode/health` и в JSON-отчёте. Ошибки регистрации настроек логируются через `say()` и не замалчиваются.
  4. *Реактивная реконфигурация сетевых слушателей*: Изменения конфигурации через `scope.subscribe()` динамически вызывают `syncListener`, перезапуская прямой мост при изменении режима (`mode`), портов, TLS или списков доступа (`allow`).
  5. *Безопасное значение по умолчанию*: Значение `mode` по умолчанию в схеме `Config` переведено в `'auto'` (вместо `'proxy'`), исключая сценарий «тихого» невыхода в сеть при чистом старте.

- 2026-09-10 — Полное покрытие схемы конфигурации в карточке настроек и безопасность сервисов (#109):
  1. *Покрытие схемы*: карточка настроек `LanModeCard` (`lib/client.js`) расширена с 6 до всех 25 интерактивных полей схемы `Config` (`lib/index.js`), структурированных в 7 логических секций (Сетевой шлюз, TLS и сертификаты, LAN доступ и безопасность, Мобильный интерфейс и mDNS, Браузерные полифиллы, Аутентификация, Cloudflare Tunnel).
  2. *Обоснование неинтерактивных полей*:
     - `directHost` (привязка сетевого сокета, по умолчанию `0.0.0.0`) и `tlsDir` (путь к хранилищу Root CA в ФС) фиксируются на этапе начальной загрузки процесса (host/profile-row only), так как в архитектуре Cordis изменение интерфейса привязки на лету без перезапуска контейнера/процесса недопустимо.
     - Устаревшие поля `lanPin` и `tunnelToken` помечены Deprecated и поддерживаются для совместимости со старыми конфигурациями; в UI карточки используются современные безопасные ссылки `lanPinRef` и `tunnelTokenRef`.
  3. *Устранение сбоев проксирования Cordis*: прямой доступ `ctx.settings` и `ctx.settingsScope` заменен на безопасные селекторы `(ctx.get?.('settings') || ctx.settings)` и `(ctx.get?.('settingsScope') || ctx.settingsScope)` в `lib/index.js` и `lib/client.js`.
  4. *Изоляция стилей*: тег динамических стилей `<style>` карточки снабжен обязательным атрибутом `data-dsh-plugin="dsh-lanmode"`.

- 2026-09-10 — Устранение ложной классификации мобильных устройств и защита нативного Enter (#112, GitHub #1):
  1. *Защита нативного Enter*: подтверждено и зафиксировано тестами полное отсутствие `e.stopPropagation()` и обработчиков `keydown` в `lib/mobile-nav.js`, гарантируя штатную отправку сообщений по Enter в редакторе Lexical ядра DSH на любых десктопных устройствах.
  2. *Точная классификация сенсорных устройств*: грубое условие `window.innerWidth < 1024 || maxTouchPoints > 0` заменено на строгую связку экрана и типа указателя `isNarrowScreen && (hasCoarsePointer || hasTouch)`, где `hasCoarsePointer` проверяется через `window.matchMedia('(pointer: coarse)').matches`. Ноутбуки с сенсорными экранами и узкие окна браузеров больше не активируют мобильные тач-сценарии.
  3. *Очистка мертвого кода*: удалены неиспользуемые переменные `enterSends` из `lib/mobile-nav.js`.

- 2026-09-12 — Оптимизация сетевого пула соединений, кэширование QR-векторов и умный опрос клиента (#117):
  1. *Пул постоянных соединений апстрима (bridge.js)*: Внедрён переиспользуемый локальный `http.Agent` (`keepAlive: true`, `maxSockets: 100`, `maxFreeSockets: 20`, `keepAliveMsecs: 30000`) для проксирования запросов к петлевому интерфейсу харнесса. Устранены накладные расходы постоянного пересоздания сокетов и TCP handshake при загрузке статики и скриптов плагинов WebUI. При остановке слушателя агент корректно освобождает дескрипторы (`agent.destroy()`).
  2. *Кэширование SVG QR-кодов и поддержка ETag (qr.js, index.js)*: В модуль `qr.js` добавлен внутренний LRU-кэш на 50 элементов (`generateCachedQRSvg`), исключающий повторный расчёт многочленов Рида-Соломона. Маршрут `/dsh-lanmode/qr` снабжен заголовками `Cache-Control: public, max-age=3600` и проверкой `If-None-Match` с возвратом `304 Not Modified`, снижая сетевой и процессорный оверхед до нуля для повторных запросов.
  3. *Умный опрос клиента (client.js)*: В компоненте `QuickQrPopover` замер RTT переведён в режим по требованию: интервал опроса запускается только при открытом поповере (`open === true`) и немедленно при возврате фокуса во вкладку (`visibilitychange === 'visible'`). При закрытом окне или неактивной вкладке мобильного браузера фоновые сетевые запросы полностью прекращаются.
  4. *Тестовое покрытие*: Создан тестовый модуль `test/perf-pool-qr-117.test.mjs` с проверкой переиспользования TCP-соединения между мостом и мок-апстримом, валидацией кэширования SVG и ETag. Общее покрытие расширено до 165 тестов (100% pass).

- 2026-09-12 — Завершение комплексного пакета оптимизаций стабильности, памяти и мобильного UX (пункты 4–10, #119):
  1. *Порог потокового сжатия (bridge.js)*: Пропуск gzip/brotli сжатия для ответов с размером менее 1024 байт (`content-length < 1024`). Это полностью исключает процессорный оверхед архивации для мелких JSON-ответов и статусов.
