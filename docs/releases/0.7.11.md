# Релиз v0.7.11 — Устранение гонки запасного пути конфигурации со службой настроек

## Зачем выпускаем
Начиная с версии хоста DSH `0.1.5-alpha.1` сборка дерева сервисов и плагинов стала занимать больше времени (>10 секунд). В `@goodandready/dsh-lanmode` двухсекундный таймер запасного пути конфигурации в `apply()` успевал сработать раньше, чем ядро передавало сервис `settings`. В результате плагин молча поднимался с пустым конфигом ряда и схемным значением по умолчанию `mode: 'proxy'`, не открывая сетевых слушателей (`ERR_CONNECTION_REFUSED`).

Релиз `v0.7.11` полностью устраняет эту архитектурную проблему, переводит инициализацию на нативный механизм Cordis и обеспечивает реактивное обновление слушателей прямого моста.

## Что изменено и исправлено
1. **Нативная инжекция зависимостей**:
   - Служба `settings` объявлена в `export const inject = ['webServer', 'settings']`. Cordis гарантированно ожидает полной инициализации службы настроек перед запуском `apply()`.
2. **Устранение гонки таймера**:
   - Двухсекундный таймер-гонка удален из `apply()`. Настройки считываются синхронно и бескомпромиссно при готовности сервисов.
3. **Логирование и видимость ошибок регистрации**:
   - Ошибки регистрации настроек в `settings.register()` больше не поглощаются молча. Они выводятся в журнал с префиксом `say()` и фиксируются в поле `configWarning`.
4. **Реактивная реконфигурация сетевых слушателей**:
   - При обновлении конфигурации в интерфейсе (через подписку `scope.subscribe()`) функция `syncListener` автоматически перезапускает слушатели прямого моста на новых портах или с обновленными параметрами TLS/доступности без необходимости перезагружать хост.
5. **Прозрачность источника настроек на странице диагностики**:
   - На страницу `/dsh-lanmode/health` и в JSON-отчет `hostReport` добавлены поля `configSource` (`settings` | `row` | `defaults`) и `configWarning`.
6. **Безопасный fallback режима**:
   - Значение по умолчанию для параметра `mode` в схеме `Config` изменено с `'proxy'` на `'auto'`. При чистом запуске плагин сам проверяет доступность локальных адресов и поднимает слушатели, исключая скрытый отказ работы.

## Совместимость и миграции
- Полная обратная совместимость.
- Пользователям, использовавшим временный обход с дублированием настроек в строке плагина профиля DSH, рекомендуется удалить этот дубль — настройки теперь штатно берутся из `settings.yaml`.
