# v0.7.9 — Оптимизация стабильности, производительности стриминга и неинвазивность UI / Stability, Streaming Performance & Clean UI Integration

## Зачем выпускаем / Motivation
Релиз v0.7.9 направлен на устранение узких мест производительности сетевого моста, предотвращение разрывов WebSocket-соединений, обеспечение мгновенной доставки токенов LLM-стриминга в реальном времени, а также очистку интерфейса от паразитного вмешательства (оверинжиниринга) в мобильном режиме.

## Что добавлено и оптимизировано / Improvements & Optimizations
- **#100 Неблокирующая отложенная запись DeviceRegistry (`lib/devices.js`)**:
  - Устранена синхронная запись `fs.writeFileSync` на каждый входящий HTTP/WS запрос при вызове `deviceRegistry.touch()`, приводившая к микрофризам Node.js Event Loop.
  - Реализован механизм `scheduleSave` с 5-секундным дебаунсом и таймером с `unref()`.
  - Изменения в памяти (`Map`) регистрируются мгновенно.
  - Критические операции (отзыв сессий `revoke`, аварийный сброс `revokeAll`, выгрузка плагина) инициируют немедленный сброс на диск (`flush()`).
- **#100 Нулевая задержка вывода стриминга LLM (SSE) (`lib/bridge.js`)**:
  - Потоки `text/event-stream` и ответы с заголовком `x-accel-buffering: no` исключены из компрессии Brotli/Gzip.
  - Токены генерации моделей выводятся в веб-интерфейс немедленно по мере поступления от апстрима, без буферизации в сжимающих стримах.
- **#100 Безопасный Keep-Alive для WebSocket (`lib/bridge.js`)**:
  - Удалена опасная инъекция сырых байтов пинга `[0x89, 0x00]` напрямую в дуплексный поток сокета во время активного обмена данными, приводившая к падениям сокетов с ошибкой 1002 (Protocol error).
  - Включен штатный сетевой TCP Keep-Alive: `socket.setKeepAlive(true, 25000)` и `upstreamSocket.setKeepAlive(true, 25000)`.
- **#100 Устранение оверинжиниринга в мобильном слое и клиенте**:
  - `lib/mobile-nav.js`: удален глобальный перехват и подавление клавиши `Enter` через `e.stopPropagation()`.
  - `lib/shim.js`: удалена глобальная блокировка `HTMLElement.prototype.focus`, мешавшая нормальному вводу текста на сенсорных устройствах.
  - `lib/mobile-styles.js`: удалено агрессивное скрытие сторонних плагинов (`terminal`, `git-graph`) через селекторы с `!important`.
  - `lib/client.js`: интервалы опроса реестра устройств (`/devices`, 20с) и туннеля (`/tunnel`, 10с) активируются строго при открытой карточке настроек (`open === true`), экономя ресурсы сети и батареи.
- **#100 Безопасная работа с брандмауэром (`lib/firewall.js`)**:
  - Команды проверки и настройки брандмауэра ОС корректно и тихо обрабатывают отсутствие прав суперпользователя без генерации ошибок в журнал.
