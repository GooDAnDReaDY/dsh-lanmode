# v0.7.8 — Authoring Quality Gate & Reactive Settings Binding

## Добавлено / Added
- **#95 Реактивная карточка настроек через `settingsScope`**: в клиенте объявлен `inject: ["slots", "locale", "settingsScope"]`, в компонент `LanModeCard` встроена нативная форма управления параметрами сетевого режима (`mode`, `directPort`, `tls`, `allow`, `unlockPrivileged`, `lanPinRef`). Форма слушает обновления снимка `settingsScope`, валидирует порты и сохраняет все поля с визуальной индикацией статуса.
- **#96 Ссылки на credentials (`lanPinRef` и `tunnelTokenRef`)**: в схему `Config` добавлены безопасные ссылки на учетные данные; реализован модуль `lib/secret.js` с функцией `resolveSecret`, которая разрешает значения через сервис `ctx.credentials` и переменные окружения. Прямые строковые поля `lanPin` и `tunnelToken` сохранены в режиме `Deprecated` для 100% обратной совместимости.

## Исправлено / Fixed
- **#97 Устранение утечки клиентских слушателей**: регистрация обработчиков `turn/end`, `approval/asked`, `visibilitychange` и `focus` переведена в `ctx.effect` с меткой `dsh-lanmode-client-listeners` и возвратом функций отписки (`disposers`), исключая утечки памяти при перезагрузке плагина.

## Тесты / Tests
- Добавлен тестовый модуль `test/audit-authoring-95-96-97.test.mjs` (3 подтеста). Все 138 тестов проходят успешно.
