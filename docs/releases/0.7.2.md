# v0.7.2 — Hotfix for Client Bundle SyntaxError

## Исправлено / Fixed

- **#76 Устранена синтаксическая ошибка `SyntaxError: Unexpected token ']'` в `lib/client.js`**. Лишний закрывающий блок `} }, [])` на строках 124-126 прерывал выполнение общего браузерного JavaScript-бандла плагинов `/plugins/??...`, из-за чего плагины в цепочке не могли зарегистрироваться через `window.__ModuleLoader__.load`.
- Добавлен автоматический регрессионный тест `test/client-bundle-syntax.test.mjs`, валидирующий синтаксис всех файлов в `lib/*.js` через `node --check`.
