# Заметки о выпуске v0.7.14

## Зачем выпускаем
Плановое минорное обновление `v0.7.14` (z-bump) направлено на радикальное повышение скорости работы сетевого прокси, оптимизацию использования памяти и процессора, а также обогащение нативного мобильного пользовательского опыта при доступе к DeepSeek Harness со смартфонов и планшетов.

## Что добавлено и изменено
1. **HTTP Keep-Alive Connection Pooling (`lib/bridge.js`)**:
   - Внедрен постоянный пул локальных соединений `http.Agent({ keepAlive: true, maxSockets: 100, maxFreeSockets: 20, keepAliveMsecs: 30000 })` для запросов прямого моста к петлевому интерфейсу ядра DSH.
   - Исключены повторные TCP-хэндшейки и накопление `TIME_WAIT` сокетов при массовой загрузке скриптов и ассетов WebUI.
   - Обеспечено корректное закрытие сокетов через `agent.destroy()` при остановке слушателя.

2. **Кэширование векторных QR-кодов и HTTP ETag (`lib/qr.js`, `lib/index.js`)**:
   - Добавлена функция `generateCachedQRSvg` с внутренним LRU-кэшем на 50 элементов, исключающая повторный дорогостоящий расчет многочленов Рида-Соломона в поле Галуа GF(256).
   - Маршрут `/dsh-lanmode/qr` снабжен заголовками `Cache-Control: public, max-age=3600` и `ETag` с поддержкой условных ответов `304 Not Modified` с нулевой передачей тела.

3. **Smart Client Polling (`lib/client.js`)**:
   - В компоненте быстрого входа `QuickQrPopover` опрос сетевой задержки (RTT) переведен на работу по требованию: таймер активен только при открытом поповере (`open === true`) и при возврате фокуса в браузер (`visibilitychange === 'visible'`).

4. **Порог потокового сжатия (`lib/bridge.js`)**:
   - Добавлен порог размера (`minSize = 1024B`): для ответов с известной длиной менее 1 КБ потоковое сжатие gzip/brotli отключается, полностью исключая холостую нагрузку на CPU при передаче мелких JSON-пакетов.

5. **Сборка мусора и ограничение емкости сессий (`lib/auth.js`)**:
   - В `AuthManager` внедрен лимит емкости активных сессий (`maxSessions = 500`) с вытеснением старейших по дате создания.
   - Добавлен автоматический таймер `cleanupExpired` (раз в час) для очистки истекших сессий и старых записей IP-адресов брутфорс-контроля (старше 1 часа).

6. **Zero-Downtime Graceful Hot Reload (`lib/index.js`, `lib/bridge.js`)**:
   - Остановка слушателя прямого моста переведена на асинхронное ожидание событий закрытия сокетов (`Promise.all(closers)`), предотвращая ошибку `EADDRINUSE` при быстрой смене портов на лету в `onConfigUpdated`.

7. **Нативная интеграция Web Share API (`lib/client.js`)**:
   - В окно мобильного входа добавлена системная кнопка «Поделиться ↗» (`navigator.share`), позволяющая в один клик отправлять адрес харнесса на мобильные устройства (AirDrop, Nearby Share, Telegram).

8. **PWA App Badging и Haptic Feedback (`lib/client.js`)**:
   - Реализовано обновление счетчика непрочитанных ответов агента на значке PWA (`navigator.setAppBadge`) при фоновых событиях `turn/end` с автоматическим сбросом при возврате активности во вкладку (`clearAppBadge`).
   - Обеспечен тактильный виброотклик (`navigator.vibrate`) на мобильных устройствах при завершении ответов и подтверждении инструментов (`approval/asked`).
