# v0.7.10 — Аутентификация по логину и паролю и фирменная страница входа / Password Authentication & Branded Login Page

## Зачем выпускаем / Motivation
Релиз v0.7.10 реализует защиту любого входа в веб-интерфейс DeepSeek Harness с помощью аутентификации по логину и паролю. Функция настраивается непосредственно в карточке плагина в настройках DSH и встречает пользователей фирменной страницей входа в нативной палитре Catppuccin Mocha.

## Что добавлено и улучшено / What's New
- **#103 Двухуровневая защита любого входа (HTTP + WebSocket)**:
  - При включенной опции `passwordAuth: true` весь неавторизованный входящий трафик (HTML, REST API, WebSocket) блокируется на уровне прямого моста `lib/bridge.js` и ранней клиентской заплатки `lib/shim.js`.
  - Публичными остаются исключительно маршруты авторизации (`/dsh-lanmode/auth/login`, `/dsh-lanmode/auth/logout`, `/dsh-lanmode/auth/session`), фавиконка `/favicon.ico`, корневой сертификат `/dsh-lanmode/ca.crt` и PWA манифест `/dsh-lanmode/manifest.json`.
- **#103 Криптографическая безопасность и сессии (`lib/auth.js`)**:
  - Модуль `AuthManager`:
    - Сравнение паролей через `crypto.timingSafeEqual` с предварительной проверкой длины буферов, полностью исключающее тайминг-атаки.
    - Генерация криптостойких случайных 256-битных токенов сессий (`crypto.randomBytes(32)`).
    - Защита от перебора паролей (Rate Limiting): автоматическая блокировка по IP-адресу на 30 секунд при превышении 5 неверных попыток ввода.
    - Безопасное хранение секретов через ссылки на хранилище credentials (`authPasswordRef` / `ctx.credentials` / ENV), предотвращающее утечку паролей в JSON-снимках настроек.
    - Сессионные куки `dsh_auth_session` со сроком действия 30 дней (`HttpOnly; SameSite=Lax; Path=/; Max-Age=2592000`).
- **#103 Фирменная страница входа (`lib/login-page.js`)**:
  - Высококачественный интерфейс в стиле Catppuccin Mocha (`#11111b`, `#181825`, `#313244`, `#cdd6f4`, индиго `#6366f1`).
  - Нулевая зависимость от внешних библиотек и CDN — рендерится сервером из Node.js.
  - Адаптивный тач-дизайн: 16px шрифт в полях ввода против нежелательного зума на iOS/iPad, тач-таргеты 44px, safe area insets.
  - Переключатель показа/скрытия пароля, интерактивные анимации shake при ошибке, индикатор защищённого HTTPS соединения.
- **#103 Интеграция в панель настроек (`lib/client.js`)**:
  - Поля `passwordAuth`, `authUser`, `authPassword`, `authPasswordRef` синхронизируются с `settingsScope`.
  - Кнопка «Выйти из системы» для быстрого завершения текущей сессии (`POST /dsh-lanmode/auth/logout`).
- **#103 Ранняя клиентская защита (`lib/shim.js`)**:
  - Перехват ответов HTTP 401 с заголовком `x-dsh-auth-required` и автоматическое перенаправление на корень `/` для показа формы входа.

## Совместимость и миграции / Compatibility
- Полная 100% обратная совместимость: по умолчанию опция `passwordAuth: false` выключена, стандартное поведение доступа не изменяется.
- Никаких миграций баз данных или конфигураций не требуется.
