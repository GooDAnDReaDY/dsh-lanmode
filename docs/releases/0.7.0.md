# v0.7.0 — Mobile Touch Adaptation, Quick-Access UI, Cloudflare WAN Tunnels, and Device Session Roster

## Резюме / Summary

Крупное обновление (39 реализованных задач в 8 функциональных блоках), превращающее `@goodandready/dsh-lanmode` из базового сетевого шлюза в полноценный мобильный и WAN портал доступа к DeepSeek Harness.

A major milestone release (39 features across 8 blocks) transforming `@goodandready/dsh-lanmode` into a comprehensive mobile and remote WAN gateway for the DeepSeek Harness Web UI.

---

## Что нового / What's New

### 1. Мобильная адаптация и жесты / Mobile Touch & Navigation (Blocks 1 & 2)
- **#36 iOS Anti-Zoom**: принудительный `font-size: 16px` на инпутах и textarea на экранах `< 1024px` для полного исключения нежелательного авто-масштабирования страницы в мобильном Safari.
- **#37 Safe-Area Insets**: точный расчет `env(safe-area-inset-bottom)` и `safe-area-inset-top` для плавающей панели ввода чата.
- **#38 Touch Targets 44×44px**: расширенные зоны нажатия для сенсорных устройств (`pointer: coarse`).
- **#40 Подавление фокуса**: блокировка паразитного вызова экранной клавиатуры при первичной загрузке страницы.
- **#45 Подавление тултипов**: устранение залипающих десктопных hover-подсказок на сенсорных экранах.
- **#39 Опция «Enter = Новая строка»**: настраиваемое поведение клавиши Enter на мобильных сенсорных клавиатурах (`mobileEnterSends`, по умолчанию `false`).
- **#41 Авто-сворачивание панелей**: автоматическое скрытие тяжелых десктопных панелей (детали, терминал, git-graph) на экранах `< 768px`.
- **#42 Свайп-навигация**: поддержка жестов смахивания от левого края для открытия и закрытия бокового меню.
- **#43 Схлопывание меню**: автоматическое закрытие сайдбара при переходе в диалог на мобильном устройстве.
- **#44 Floating Action Button**: плавающая кнопка быстрого открытия сайдбара на смартфонах.
- **#72 Принудительно десктопный вид**: переключатель `forceDesktopMode` для планшетов и iPad.
- **#73 Тактильный виброотклик**: вызов `navigator.vibrate` при событиях `turn/end` и запросах разрешений `approval/asked`.

### 2. Интеграция в интерфейс DSH и PWA / Quick Access & PWA (Block 3)
- **#68 & #69 Quick QR Popover**: кнопка в подвале сайдбара (`sidebar.footer`) и всплывающее окно быстрого доступа со скачиванием Root CA, копированием URL и SVG QR-кодом.
- **#70 ASCII QR в терминале**: вывод компактного текстового QR-кода прямо в терминал сервера при запуске.
- **#71 Индикатор смартфона**: бейдж онлайн-активности мобильного клиента в интерфейсе десктопа.
- **#74 PWA Manifest & Splash**: расширенный манифест PWA с категориями, ярлыками быстрого перехода и splash-экраном.

### 3. Сетевая надежность и производительность / Network Reliability (Block 4)
- **#64 Потоковая компрессия**: прозрачное сжатие ответов Brotli и Gzip через встроенный `node:zlib`.
- **#65 WebSocket Heartbeat**: отправка RFC 6455 Ping кадров каждые 25 секунд для предотвращения сброса NAT сотовыми операторами.
- **#66 Быстрое переподключение**: моментальное восстановление сессии при возврате во вкладку (`visibilitychange`).
- **#67 RTT Latency**: измерение и отображение сетевой задержки пинга в реальном времени.

### 4. Системный сетевой стек и фаерволы / System Firewall & Discovery (Block 5)
- **#58 Автоопределение хоста в WSL2**: нахождение физического IP Windows-хоста через шлюз `resolv.conf`.
- **#59 & #60 Управление брандмауэром**: автоматическое открытие TCP порта в Windows Defender Firewall (`netsh advfirewall`) и Linux (`ufw` / `firewalld`).
- **#61 Селектор сетевых интерфейсов**: фильтрация и выбор сетевых адаптеров в `localAddresses()`.
- **#62 Поддержка Tailscale**: распознавание CGNAT диапазона `100.64.0.0/10` и включение в SAN TLS-сертификатов.
- **#63 Диагностический эндпоинт**: порт-проб `/dsh-lanmode/probe` для самодиагностики.

### 5. Реестр устройств и безопасность / Device Roster & Security (Blocks 6 & 7)
- **#51 Реестр сопряженных устройств**: распознавание ОС и браузера по User-Agent (iPhone, Android, Windows, Mac).
- **#52 Онлайн статус**: фиксация `lastSeenAt` и бейджи реального времени.
- **#53 Отзыв сессий**: возможность индивидуального отзыва любого подключенного устройства.
- **#54 Emergency Kill Switch**: кнопка мгновенного аварийного сброса всех активных сессий.
- **#55 Клиентский PIN-модал**: нативное диалоговое окно запроса PIN-кода при ответе HTTP 403.
- **#56 Защита от брутфорса**: блокировка IP на 30 секунд после 5 неудачных попыток ввода PIN с HTTP 429.
- **#57 PWA Session Restore**: зеркалирование хранилища для защиты от сброса сессий при вытеснении страницы iOS WebKit из памяти.

### 6. Cloudflare WAN Tunnels / Remote Access (Block 8)
- **#46 Cloudflare Tunnels Driver**: нативный драйвер Quick Tunnels (`trycloudflare.com`) и Named Tunnels (run `--token`).
- **#47 Авто-парсинг URL**: захват выданного публичного адреса из вывода `cloudflared`.
- **#48 QR для WAN**: динамический QR-код для входа через интернет.
- **#49 Динамический Toggle**: запуск и остановка туннеля через API `/dsh-lanmode/tunnel/toggle` и UI настроек без перезапуска сервера.
- **#50 Защита WAN трафика**: обязательная верификация PIN-кода для входящих запросов из сети Cloudflare (`isCloudflareRequest`).
