# Release v0.7.13 — Унификация визуального стиля по стандарту clinebot и комплексная оптимизация стабильности (#114)

## Зачем выпускаем
Релиз v0.7.13 приводит интерфейс плагина dsh-lanmode к единому современному стандарту дизайна DSH-плагинов (на основе эталона dsh-clinebot) и устраняет выявленные в ходе глубокого аудита риски нестабильности в сетевых потоках, хранении устройств и обработке WebSocket-соединений.

## Что добавлено и улучшено

### 1. Визуальная унификация (стандарт dsh-clinebot)
- **Изоляция сбоев через ErrorBoundary**: Карточка LanModeCard (lib/client.js) оснащена React Class Component ErrorBoundary. Любые ошибки жизненного цикла компонентов формы перехватываются (getDerivedStateFromError, componentDidCatch) и отображают аккуратный блок с описанием и кнопкой «Повторить» без краша других вкладок настроек DSH.
- **Системные дизайн-токены ядра**: Все элементы переведены на токены --dsw-alias-border-l2, --dsw-alias-bg-layer-2, --dsw-alias-bg-layer-3, --dsw-alias-label-primary, --dsw-alias-state-brand-primary, --dsw-alias-state-success-primary, --dsw-alias-state-error-primary.
- **Карточная иерархия секций**: Форма структурирована с помощью классов .lm-form-box, .lm-section-card, .lm-section-title, .lm-section-desc, .lm-btn-primary, .lm-btn-danger, .lm-badge-ok/warn/bad.
- **Изоляция стилей**: Динамический тег style снабжен атрибутом data-dsh-plugin="dsh-lanmode".

### 2. Комплексная оптимизация стабильности
- **Резильентность потокового сжатия (lib/bridge.js)**: Добавлен перехват ошибок stream.on('error') и очистка сокетов при разрыве клиентом res.on('close') для потоков brotli/gzip. Это предотвращает падения процесса по неперехваченным исключениям и утечки системных буферов.
- **Ограничение емкости реестра устройств (lib/devices.js)**: Метод touch() теперь жестко ограничивает пул активных устройств до 200 записей с автоматическим вытеснением наименее активных по lastSeenAt. Добавлена устойчивость к поврежденным JSON-файлам при старте.
- **Синхронизация сессий (lib/auth.js)**: Валидация сессионных токенов через deviceRegistry.isRevoked() теперь автоматически аннулирует сессию, а revokeSession() надежно транслирует отзыв в реестр устройств.
